# CodeEscape_Assignment3
CodeEscape 🎮

Unity Game Development | Assignment 3

CodeEscape is a Unity game developed for the Game Development course at Ariel University. The project focuses on level design, interactive gameplay, and building a playable experience for web and Android.

🎯 Project Overview

The project includes:

* A playable game level with interactive mechanics.
* Player controls, collisions, and game objectives.
* Level-design documentation covering different difficulty levels.
* WebGL and Android build support.

🛠️ Technologies

* Engine: Unity 6
* Language: C#
* Platforms: WebGL and Android
* Version Control: GitHub

📁 Project Structure

* Assets/ – Game scenes, scripts, models, and prefabs.
* Packages/ – Unity package dependencies.
* ProjectSettings/ – Unity project configuration.
* Submission/ – Level designs and implementation documentation.

🚀 How to Run

1. Clone or download this repository.
2. Open the project using Unity Hub.
3. Use Unity 6.6 or a compatible version.
4. Open Assets/Scenes/Main.unity.
5. Press Play to start the game.

📱 Builds

The project supports WebGL for browser gameplay and Android APK builds for mobile devices.
